A standalone Windows package with a private Python runtime and one shared application for personal and public use.

- Tray settings: computer-only, local network and optional Tailscale; active addresses and version.
- Opaque Light/Dark surfaces behind header branding, counts, headings and footer; existing dashboard layouts retained.
- Original purple/cyan hexagon markup restored. Header says PACE; edition and software version appear in Settings.
- Saved Custom appearance, wallpaper thumbnails, duplicate image reuse and migration to data/backgrounds.
- Built-in and uploaded project icons under data/icons; direct icon and three-dot menu access.
- Delete project and its folder with confirmation, from cards and Reorder; directional reorder controls restored.
- Persistent editable root title across Canvas, Radial Map and Roadmap; centered/expanded layout control before Home.
