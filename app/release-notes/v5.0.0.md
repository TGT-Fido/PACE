# PACE26 v5.0.0 — candidate

This release combines the v4.9 and v5.0 features.

- Create projects and folders from any connected device.
- Upload PDFs up to 75 MB into an existing project. Older files and pins are preserved; duplicate filenames are rejected.
- Optional PDF version notes and automatic upload timestamps in History.
- Overview search across card details, badges and filenames.
- Overview + PDF contents search, with page links and excerpts. Text is indexed locally in the background; image-only/scanned and locked PDFs may not be searchable. OCR is not included.
- Full and settings-only backups in a separate configurable server folder, with archive integrity checks and safety backups before restore.
- In-app data restoration plus independent offline app/data recovery.
- Click the version button for release notes; readable copies also live in data/ReleaseNotes.
- Wallpaper brightness control.
- 24 named color swatches, custom colors and shared human-readable color names in filters.
- Configurable HTTPS update source, release notes, checksum verification, automatic full pre-update backup, detached installer, startup check and rollback.

Hosting is not configured. Online update delivery requires a published release manifest and app-only ZIP. Windows tray restarting and iPhone Safari must be verified on the actual devices before treating this candidate as a stable release.

Backup details: settings-only includes the application and card/document settings but omits project files except folder identity markers. It cannot recover deleted PDFs. In-app restore preserves the current server connection settings and restores data; use RECOVER_PACE.cmd for app recovery. Backup ZIPs are not encrypted.
