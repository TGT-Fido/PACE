# PACE26 v6.0.0 — Multi-View

Candidate build · 12 October 2026

Four ways to explore the same projects:
- Cards: the original dashboard, search, filters and PDF history.
- Canvas: a freeform map with movable project nodes and category grouping.
- Radial Map: circular nodes, animated focus/zoom, a brighter selected node, softer child glow, breadcrumbs, Zoom out and Home.
- Roadmap: a horizontal main path with branches above and below.

Each map saves its own node positions, collapsed branches, focus and zoom. Set any of the four views as the startup view. These settings are stored on the server and included in backups.

Relationships:
- Projects initially belong to their category group.
- Choose a project or group as a parent; circular parent chains are rejected.
- Add labelled related links, optionally with arrows. Remove links in Relationships.
- Connect mode lets you choose source and destination nodes directly.
- Moving nodes and changing relationships do not rename or move folders or PDFs.

Navigation:
- Tap/click to select; drag empty space to pan; scroll or pinch to zoom.
- Move nodes mode enables dragging project/group nodes.
- Home fits the visible map. Zoom out selects the parent. Focus branch fits the selection and its visible children.
- Reset this layout resets only the current map's positions, collapsed branches, focus and zoom; shared relationships remain.
- Search and filters apply across views, with ancestor nodes retained as context.

Bulk import:
- Choose multiple PDFs or drop them onto the dashboard or a card.
- Review each destination: an existing project or a new project folder on the server.
- Assign the whole batch together, split files across projects, or create one new project per PDF.
- Edit filenames and optional per-PDF version notes before import.
- One Import action processes the queue with per-file results. Failed rows can be corrected and retried; completed rows are skipped.
- Existing files are never overwritten. The 75 MB per-PDF limit remains. A failed upload can leave its newly created empty project folder.

All v5 features are retained, including PDF editing/search, named colors, backups, offline recovery and the unconfigured updater. No hosting account or release source has been set up.

Validation: automated backend and Chromium desktop/mobile checks completed. Windows tray, real iPhone/iPad Safari and hosted update delivery still need device testing. Use a separate test copy first; see README_V6.md.
