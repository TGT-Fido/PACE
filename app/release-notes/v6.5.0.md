# PACE26 v6.5.0 — Workspace and responsive controls

This candidate implements a broader workspace update across Cards, Canvas, Radial Map and Roadmap.

- Compact full-width desktop header and controls; intro block removed; map height derives from available viewport space.
- Settings gear beside Rescan, with Light/Dark mode, version, runtime server display name/reset, recursive projects-folder storage, wallpaper/brightness, release notes, backups and existing update controls.
- Layout selector/help, category/badge pill filters, rainbow color menu and color indicators.
- Two side-by-side search modes: Overview + PDF contents, then Overview. Portrait puts them above the search field.
- Stronger project borders, map connections and arrowheads; selected connections highlighted. These are ordinary CSS effects, not HDR.
- Simplified project editing omits Category and Priority without deleting existing values or category management.
- Single PDFs open without manual selection. Multiple files retain numeric series/latest and optional pins; ambiguous cases require an explicit choice.
- Desktop card-body dragging and numbered-page targets; full-screen phone reorder dialog with handles, page sections, Save/Cancel and reset preview.
- Mobile map actions use a modal sheet; controls collapse into a button. Radial/Roadmap use readable default scales while retaining existing saved cameras.
- Expand/restore for all three map layouts. Desktop includes the whole workspace; compact layouts maximize the drawing area. Restore returns to the entry position and zoom.
- Release notes use initially collapsed accordions and remain readable in data/ReleaseNotes. Supplied historical notes are sanitized; existing older notes remain preserved.
- Additive settings migration creates a dashboard checkpoint. The software package excludes live projects, PDFs, settings, logs and backups.

Validation: 52 backend tests passed, along with JavaScript syntax and static checks. Browser execution and visual/device checks were unavailable in this environment; desktop, real iPhone/iPad Safari, touch interactions and Windows tray behavior remain unverified for this candidate. See docs/VALIDATION_REPORT.md before replacing a working installation.

Updater setup/hosting, automatic release downloading and actual HDR rendering remain deferred. Earlier sanitized v1–v3.0.2 notes were not supplied and are not reconstructed.
